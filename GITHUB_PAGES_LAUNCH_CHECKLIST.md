# GitHub Pages Launch Checklist

## Repository and Pages

- [ ] ZIP extracted locally.
- [ ] Folder contents uploaded to the root of a GitHub repository.
- [ ] Default branch is `main`.
- [ ] GitHub Pages source is set to **GitHub Actions**.
- [ ] `Deploy Merrill Girls Wrestling to GitHub Pages` workflow passes.
- [ ] Public site opens on phone and desktop.
- [ ] Merrill logos, favicon, and install icon load correctly.

## Firebase Authentication

- [ ] Google and/or Email/Password provider enabled.
- [ ] `YOUR-GITHUB-NAME.github.io` added to Authorized domains.
- [ ] Any custom Pages domain added to Authorized domains.
- [ ] First administrator can sign in.
- [ ] A person who is not on the roster cannot enter the app.

## Firestore

- [ ] Firestore database created.
- [ ] Included rules deployed.
- [ ] Included indexes deployed.
- [ ] Seed content loaded.
- [ ] First administrator membership bootstrapped.
- [ ] Athlete, coach, admin, and board permissions checked.

## Real-device checks

- [ ] Athlete completes Before Practice on a phone.
- [ ] Today's 1% appears on the Practice Board.
- [ ] Athlete completes After Practice.
- [ ] A useful Went Well item can be saved to Confidence Bank.
- [ ] Coach recognition reaches the correct athlete.
- [ ] Private reflection never appears on the board.
- [ ] Site remains understandable on weak Wi-Fi.
- [ ] Install-to-home-screen works on at least one iPhone and one Android device.

## Before real athlete data

- [ ] App Check configured and monitored, then enforcement enabled when ready.
- [ ] Real roster reviewed.
- [ ] Privacy/visibility decisions approved.
- [ ] Data retention and deletion process approved.
- [ ] Coaches understand that Reset Sweep is a brief performance-focus tool, not therapy.
